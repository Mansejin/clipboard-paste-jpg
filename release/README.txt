clipboard-paste-jpg — 설치 안내
================================

[설치]
1. 이 폴더의 파일을 원하는 위치에 둡니다 (압축을 푼 상태).
2. "설치.bat" 을 더블클릭합니다.
3. 완료! 이후 로그인할 때마다 자동 실행됩니다.

[사용법]
1. Win+Shift+S 등으로 화면을 캡처합니다.
2. 탐색기에서 저장할 폴더를 엽니다.
3. Ctrl+Shift+V 를 누릅니다.

[제거]
"제거.bat" 을 더블클릭합니다.

[요구 사항]
Windows 10 / 11 (64비트)
Python 설치 불필요
